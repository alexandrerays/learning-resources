

# Learning Resources

A curated collection of study guides, coursework, and algorithm implementations focused on **AI Engineering**, **Computational Physics**, and **Machine Learning**. This repository serves as a personal learning portfolio and technical reference for software and ML engineering concepts.

## 📚 Contents

- **🤖 AI Engineering Path**: A comprehensive study guide covering core LLM/GenAI concepts, Retrieval-Augmented Generation (RAG), AI agents, evaluation frameworks, system design, and essential tools.
- **🎓 Courses**:
  - **BSc in Computational Physics**: Coursework spanning introductory programming, data structures, algorithms, databases, computer architecture, networks, and high-performance computing (HPC). Includes practical assignments and lab exercises.
  - **ML Engineer Nanodegree**: Projects and materials from the Udacity Machine Learning Engineer Nanodegree (e.g., Finding Donors, Customer Segments, Quadcopter, Bike-Sharing Demand).

## 🚀 Usage

This repository is designed for reference and self-study. To explore the materials locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/alexandrerays/learning-resources.git
   cd learning-resources
   ```

2. **Browse study guides**:
   Review the AI Engineering concepts and checklists in `ai-engineering/path-ai-engineering.md`.

3. **Run code examples**:
   The `courses/` directory contains algorithm implementations and programming assignments in C, C++, and Python. You can compile and run them using standard tools:
   ```bash
   # Example: Compile and run a C program
   gcc courses/bsc-computational-physics/data-structures/linked_list.c -o linked_list
   ./linked_list

   # Example: Run a Python algorithm
   python courses/bsc-computational-physics/data-structures/algorithms/prim_algorithm.py
   ```
